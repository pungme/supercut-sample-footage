# Supercut sample footage

Sample footage for Supercut's sample project: one scene from **Tears of Steel**, the open
movie by the Blender Foundation, cut into camera-style clips with a rough cut to start from. Supercut downloads it the
first time someone picks "Try with Sample Footage".

See [LICENSE.txt](LICENSE.txt).

The clips are in the release [sample-footage-v1](../../releases/tag/sample-footage-v1) (one zip, its SHA-256 in the
release notes). This repository holds only the footage's licence and this note, no code.
